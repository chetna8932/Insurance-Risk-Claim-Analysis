# 🚗 Car Insurance Analytics — Power BI

> A Power BI dashboard analyzing **37,500+ Car insurance policies** to uncover claim trends, risk zones, and customer profiles.

---

## 📌 What's Inside
- Claim amount & frequency by coverage zone
- Demographics impact — gender, education, marital status
- Vehicle breakdown — make, model, year, private vs. commercial
- Household income vs. risk segmentation

## 📁 Data
`insurance_policies_data.xlsx` · 37,543 rows · 16 fields including claim amount, car details, coverage zone, and policyholder demographics

## 🛠️ Built With
Power BI · Excel · Power Query · DAX

## 🚀 Run It
1. Open the `.pbix` file in Power BI Desktop
2. Relink data source to `insurance_policies_data.xlsx` if prompted
3. Click **Refresh**
